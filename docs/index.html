What is measured

The canonical series uses the existing vote/election/poll classifier. The exact series requires the words “go vote” in sequence, case-insensitively, with flexible whitespace.

How to read coverage

Each CSV includes homepage captures, completed OCR, coverage percentage, raw positives, rates, partial-week flags, the snapshot cutoff, and classifier version.

Privacy and reproducibility

The nightly job uses a database account restricted to reads and exports aggregate counts only. It never publishes OCR text or individual capture identifiers.
